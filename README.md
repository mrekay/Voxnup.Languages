Voxnup Languages Project

This project is created to publicly share language translations on Voxnup. You can report and correct translation errors. If you want to join this project as a collaborator, please contact us through Voxnup.

## Languages

| Code | Language | Keys | Status |
|---|---|---|---|
| `en` | English | 2993 | Complete (reference) |
| `tr` | Türkçe | 2993 | Complete |
| `de` | Deutsch | 1862 | 1131 keys missing |
| `ru` | Русский | 1862 | 1131 keys missing |
| `az` | Azərbaycan | 1862 | 1131 keys missing |

Missing keys fall back to English in the app. `en.json` is the reference: every key there should exist in the other files. Placeholders such as `%s` must stay as they are.
